## Matrix notes

- Count: **61 endpoint definitions** when block and unblock are counted as separate routes.
- Count: **60 logical endpoint paths** if block/unblock are grouped as one action family.
- No sorting parameters are sent.
- No concrete multipart endpoint is used.
- `status` on `GET /prices` is not transmitted despite a Dart parameter.
- `status` on `GET /admin/users` is transmitted when supplied, but omitted from the supplied API documentation.
- Response status handling is centralized in `ApiException`; 401, 403, 404, 422, and 500+ are explicitly mapped. 400, 409, and 429 are not distinct client categories.
